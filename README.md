# オンゲキ レーティングチェッカー

[ongeki-score.net](https://ongeki-score.net/) から取得したスコアデータ（JSON）を読み込み、新曲枠・ベスト枠・プラチナスコア枠の対象曲を一覧表示するブラウザ完結の非公式ツールです。次の判定ランク（またはプラチナスコアの次の★）まであといくつ必要か、そこに到達したときのレート上昇量を曲ごとに算出し、近い順にグループ分けして表示します。サーバーは使わず、`index.html` を開くだけで動作します。

## 使い方

1. `index.html` をブラウザで開く（GitHub Pages 等で公開してもOK）
2. 「データ取得」タブのブックマークレットで [ongeki-score.net](https://ongeki-score.net/) から `*_ongeki_log.json` を取得する（詳細は [bookmarklet/README.md](bookmarklet/README.md)）
3. 取得したJSONを「レーティングチェッカー」タブの「スコアデータを読込」またはドラッグ&ドロップで読み込む
4. 新曲枠・ベスト枠・プラチナスコア枠を切り替えながら、近い曲から順に伸ばしていく

読み込んだデータはセッション中ブラウザ内（sessionStorage）に保持されるため、リロードしても再読込は不要です。外部にアップロードされることはありません。

## 主な機能

### レーティングチェッカー

- 新曲枠・ベスト枠・プラチナスコア枠それぞれの対象曲を表形式で表示
- スコア枠（新曲枠・ベスト枠）: 次の判定ランクまでの残りスコアと、到達時のレート上昇量（加点）を算出し、「目前」「あと一歩」などの達成度グループで表示
- プラチナスコア枠: 現在の★（0〜5）、次の★までの推定必要プラチナスコア（≈）、+1★時の上昇量と到達後のレート値を表示
- 列見出しクリックでのソート、判定ランク範囲によるフィルタ、行ごとの削除（除外して再計算）
- 表を画像として保存（SNS共有・記録用）

### 目標

条件（対象の枠・定数範囲・難易度・達成基準）を指定して、まとめて達成状況を追跡できます。

- 対象の枠: 全曲（全譜面）／新曲枠／ベスト枠／プラチナスコア枠
- 達成基準: 判定ランク以上・スコア以上（新曲枠/ベスト枠/全曲時）、★以上（プラチナスコア枠時）
- 達成した曲は自動でリストから外れ、達成率が更新される
- 手動チェックにも対応（自己申告での達成扱い）
- 目標データはブラウザのlocalStorageに保存され、次回訪問時も引き継がれる

### データ取得

- ongeki-score.net からスコアデータを取得するブックマークレット／コンソールスクリプトを提供（詳細は [bookmarklet/README.md](bookmarklet/README.md)）
- 譜面定数の欠損・推定値は、公開されている定数表（[reiwa.f5.si](https://reiwa.f5.si/) の `ongeki_record.json`）から自動補完（サイト側の確定値は常に優先）

## レート計算について

- 総合RATING = 新曲枠・ベスト枠・プラチナスコア枠それぞれの「レート寄与値（枠内レート値の合計 ÷ 50）」の合計
- 各曲の「レート値」は ongeki-score.net が算出した値をそのまま採用（ベル数由来の成分を含むため、スコアと譜面定数だけでは完全には再現できません）
- 「加点」（新曲枠/ベスト枠）はスコア補正の差分のみで決まるため正確に算出できます
- プラチナスコア枠のレート値は「譜面定数² ÷ 1000 × ☆数」

### プラチナスコアの★としきい値

公式発表（オンゲキ Re:Fresh）による、各譜面の最大プラチナスコアに対する達成率のしきい値です。

| 達成率 | ★ |
|---|---|
| 94%以上 | ★1 |
| 95%以上 | ★2 |
| 96%以上 | ★3 |
| 97%以上 | ★4 |
| 98%以上 | ★5 |

各譜面の最大プラチナスコア自体（ノーツ構成依存）は非公開で、今のJSON取得データにも含まれていません。そのため「次のプラチナスコア」欄は、現在の★帯（1%幅）の中央値を仮の達成率とみなして最大値を逆算した**概算値（≈）**です。★0（達成率94%未満）の曲は幅が広すぎて信頼できる推定ができないため「?」と表示します。

## 譜面定数データについて

譜面定数・レート値は基本的に ongeki-score.net が算出した値をそのまま使用します。以下の場合のみ、[音ゲーツール置き場](https://reiwa.f5.si/) の定数表（`ongeki_record.json`）で補完します。

- ongeki-score.net 側に定数が無い曲
- ongeki-score.net 側が推定扱いだが、定数表では確定している曲

サイト側の確定値はそのまま尊重し、上書きしません。対象は新曲枠・ベスト枠・プラチナスコア枠・全譜面のすべてです。取得した定数表はブラウザに一時キャッシュ（localStorage・約1.2MB／7日間）され、次回以降の読み込みを高速化します。「データ取得」タブから手動で再取得（キャッシュ更新）も可能です。

## 注意事項

- 当ツールは非公式のファンツールであり、株式会社セガをはじめとする関係者・関係会社とは一切関係ありません。
- スコアの取得は [ongeki-score.net](https://ongeki-score.net/) に依存しています。ご利用の際は配布元の方針に従ってください。
- ダウンロードされるJSONにはプレイヤーネームや個別のスコアが含まれます。公開の場に上げる際は取り扱いに注意してください。
- プラチナスコア枠の「次のプラチナスコア」は概算値です。実際の必要スコアと差が出ることがあります。
