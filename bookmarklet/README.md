# スコア取得ブックマークレット

[ongeki-score.net](https://ongeki-score.net/) のユーザーページから自分のオンゲキのスコアデータ（新曲枠・ベスト枠・プラチナスコア枠・全譜面・プロフィール）を取得し、`index.html` が読み込める形式のJSONファイル（`*_ongeki_log.json`）としてダウンロードするブックマークレットです。

譜面定数・レート値は ongeki-score.net が算出した値がJSONに含まれるため、maimai版と違い外部の定数表は不要です。

## 中身

- [`../ongeki_collect_console.js`](../ongeki_collect_console.js) — 読みやすい形式のソース（DevToolsコンソールにそのまま貼り付けても動きます）
- [`bookmarklet.txt`](bookmarklet.txt) — ブラウザのブックマークに登録する一行版（`javascript:...`）

## 登録方法

1. `bookmarklet.txt` の中身を全部コピーする
2. ブラウザで新しいブックマークを作成する
3. 名前を「オンゲキスコア取得」など好きな名前にする
4. URL欄にコピーした内容をそのまま貼り付けて保存する

（`index.html` の「データ取得」ページからは、ドラッグ登録・クリックでコピーもできます。）

## 使い方

1. [ongeki-score.net](https://ongeki-score.net/) にログインする
2. **自分のユーザーページ（`/user/数字/…` ならどのタブでも可）を開いた状態で**、登録したブックマークをクリックして実行する
3. 数十秒後に `*_ongeki_log.json` がダウンロードされる（`/rating` と `/technical` を取得します）
4. そのファイルを `index.html` の「スコアデータを読込」またはドラッグ&ドロップで読み込む

## トラブルシューティング

**うまく動かない・失敗する場合**

- ブックマークレットは **ongeki-score.net の自分のユーザーページを開いた状態**で実行してください。別サイトや `chrome://` から始まるブラウザ内部ページでは、同一オリジンでの取得ができず失敗します。
- サイト側のセキュリティ設定（CSP）で `javascript:` ブックマークレットがブロックされる場合は、`../ongeki_collect_console.js` の中身を **DevToolsのコンソールに貼り付けて実行**してください。取得内容は同じです（`index.html` の「データ取得 → ② コンソールに貼り付け」からコピーできます）。

## 注意

- ダウンロードされるJSONにはプレイヤーネームや個別のスコアが含まれます。公開の場に上げる際は取り扱いに注意してください。
- 当ツールおよびブックマークレットは非公式のファンツールであり、株式会社セガをはじめとする関係者・関係会社とは一切関係ありません。スコアの取得は [ongeki-score.net](https://ongeki-score.net/) に依存しています。ご利用の際は配布元の方針に従ってください。
